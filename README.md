# WedInvite website preview

This download contains the redesigned website, ten interactive invitation templates, the admin dashboard, and ten sample invitations.

## Run locally

1. Download and extract `wedinvite-preview.zip`.
2. Install Node.js 24.
3. Open a terminal in the extracted `wedinvite-preview` folder.
4. Run `npm ci`, then `npm run dev`.
5. Open http://localhost:3000.

Admin: http://localhost:3000/admin

Demo username: `demo`

Demo password: `WedInvite-Demo-2026!`

These are local demonstration credentials. Replace them before a public deployment.

See the included README and STUDIO_OPERATIONS.md for full instructions. This branch hosts the download without changing the main application branch.
