## 1. Design & Engineering Philosophy

To be truly "money-worthy" and justify premium pricing (Rs. 4,999 to Rs. 7,999+ per wedding), an e-invitation cannot be a flat image, static PDF, or generic web form. It must recreate the sensory opulence of opening a physical Rs. 20,000+ luxury invitation box with velvet, wax seals, gold foil, and scented paper.

### Script Execution & Gesture Guarantees
1. **Zero External Obfuscated Guards:** Every new template is written with clean, standards-compliant TypeScript / ES6 JavaScript. No takedown routines, no domain locks, no `throw new Error` traps.
2. **60fps Fluid Motion:** Animations leverage hardware-accelerated CSS `transform: translate3d(...)` and SVG filter shaders, ensuring smooth performance on iPhones and Android devices.
3. **Soundtrack Engine:** Web Audio API with soft fade-in on user gesture, respectful volume levels, and persistent mute memory in `sessionStorage`.
4. **Offline Resilience:** All CSS, fonts, SVG vectors, and particle scripts are self-contained or reliably cached.
